# Сезонный календарь Полярика

Топ-5 самых часто заказываемых товаров по каждому месяцу года.

Страница: [index.html](index.html)

## Данные

Сведены четыре выгрузки заказов за период май 2022 — сентябрь 2026:
**11 608 заказов**, 399 696 товарных позиций.

## Как считался топ

- Ранг — число заказов, в которых встретился товар, а не количество проданных штук.
- Товары сведены без размерного ряда: «Бейсболка детская (50-52)» и «(52-54)» — одна позиция.
- Названия, различавшиеся только регистром, объединены.
- Все годы сведены в один календарный год, месяц к месяцу.

Цвет на странице кодирует тип ассортимента — лето, демисезон, зима.

## Ограничения

- Выгрузки покрывают годы неравномерно: у января — апреля нет 2022 года, у октября — декабря нет 2026-го.
- Июнь (383 заказа), июль (274) и декабрь (164) собраны на малом числе заказов — порядок внутри топ-5 там менее устойчив. На странице они помечены пунктиром.

## Индексация

Страница закрыта от поисковых систем через `robots.txt` и `<meta name="robots">`.
Это убирает её из выдачи, но не ограничивает доступ: репозиторий публичный,
и страницу откроет любой, у кого есть ссылка.
